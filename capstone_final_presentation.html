프로젝트 시작점과 문제 재정의

“성공 여부를 맞히는 문제”에서 “성장기업 패턴을 해석하는 문제”로

1문제

성장 가능성 높은 기업을 객관적으로 판단하기 어렵다.

2의문

모델 성능을 어떤 기준으로 믿을 수 있는가?

3검증

Baseline, 신호, 분포, 잔차를 수학적으로 확인한다.

4해석

성장기업 패턴 유사도와 신뢰도 플래그로 표현한다.

초기 문제의식

  • 정보 비대칭 — 스타트업의 성장성·투자·매출 정보는 분산되어 있다.
  • 판단 기준 부족 — 취업준비생은 “성장 가능한 기업인가?”를 데이터로 판단하기 어렵다.
  • 분석 재정의 — 성공확률 예측을 기업 탐색 보조지표 문제로 바꾸었다.

분석 문제의 수학적 형태

xᵢ = 기업 정보 벡터
yᵢ ∈ {0.1, 0.3, …, 0.9}
목표: f(xᵢ) ≈ yᵢ

입력 xᵢ는 설립연도, 분야, 투자단계, 매출, 직원 수, 투자금, 고객수, SNS 지표 등으로 구성된다.

수학적 근거 1 — 오차 분해와 신호 정량화

R²=0.034가 말하는 것: Bias-Variance-Irreducible 분해로 성능 천장을 증명한다

① 오차 분해 (Bias–Variance–Irreducible)
RMSE² = Bias²(ŷ) + Var(ŷ) + ε²
환원불가 오차 ε ≈ √(1 − R²) × σ_y
σ_y = 0.2417, R² = 0.034
∴ ε ≈ 0.2417 × √0.966 ≈ 0.2376

R²=0.034는 입력 변수로 설명 가능한 분산이 3.4%뿐임을 의미한다. 나머지 96.6%는 현재 피처로 줄일 수 없는 노이즈다.

② Stratified 5-Fold CV
y ∈ {0.1, 0.3, …, 0.9} → pd.factorize(y)
CV-RMSE = (1/K) Σₖ RMSE_k, K=5
Stratify → 각 fold에서 class 비율 보존

target이 이산형이므로 일반 KFold를 쓰면 특정 fold에 0.1이나 0.9가 몰릴 수 있다. Stratified는 모든 fold에서 동일한 class 분포를 유지해 평가 안정성을 높인다.

③ Mutual Information — 신호 크기 정량화
I(X ; Y) = H(Y) − H(Y | X)
H(Y) = −Σ P(y) log P(y)
MI(고객수, y) = 0.02989 → 약한 비선형 신호

MI=0이면 완전 무신호, MI가 클수록 예측 유용성이 높다. 최대 MI 0.02989는 신호가 존재하나 실용적 크기가 제한적임을 수치로 보여준다.

④ Permutation Test — 가설 검정
H₀: 피처 ⊥ target (무작위)
p = #{RMSE_shuffled ≤ RMSE_actual} / N
p = 0.000 → H₀ 기각, 신호 존재 확인
단, RMSE_actual = 0.2401 vs baseline 0.2417
통계적 유의 ≠ 실용적 유의

p=0.000은 신호가 존재함을 증명하지만, baseline 대비 개선이 0.64%에 불과해 통계적 유의가 서비스 성능으로 이어지지 않는다.

예측값 하나 뒤에 있는 세 가지 수학 구조: 확신도 · 외삽 위험 · 수축 보정

① Shannon Entropy → 모델 확신도
H = −Σₖ P(cₖ|x) · log P(cₖ|x)
H_norm = H / log(K), K=8
confidence = 1 − H_norm
확률이 한 class에 집중 → H↓ → 확신도↑

분류 모델이 8개 class에 균등하게 확률을 분산시키면 H_norm→1, confidence→0. 반대로 특정 class에 집중되면 confidence→1. 이 값이 riskFlags의 "모델 확신도" 기준이다.

② OOD 거리 D(x) — 외삽 위험 탐지
z_j = (x_j − μ_j) / σ_j (train 기준 표준화)
D(x) = √(Σⱼ z_j²)
D ≤ q70: 학습 분포 내
D > q90: 외삽 위험 높음

마할라노비스 거리의 단순화 버전. train 피처의 평균·표준편차로 표준화 후 유클리드 거리를 계산한다. 70%·90% 분위수로 위험 구간을 구분했다.

③ Shrinkage 후처리
ŷ_cal = ȳ + α(ŷ − ȳ), α ∈ [0, 1.2]
α=0: 전체 평균 예측 (baseline)
α=1: 원 예측 유지
rf_clf_ev_all: α=1.00 선택 → 수축 불필요

α<1이면 예측을 평균 쪽으로 수축해 과도한 변동을 줄인다. α=1.00 선택은 EV 모델의 예측이 이미 충분히 안정적임을 의미한다. rounding은 RMSE를 악화(0.2389)시켜 탈락했다.

④ 전체 수식 집약
문제: f(xᵢ) ≈ yᵢ, yᵢ ∈ {0.1,…,0.9}
모델: ŷ = Σₖ P(cₖ|x)·cₖ (EV)
검증: CV-RMSE = (1/5)Σ RMSEₖ = 0.2375
한계: R²=0.034, ε≈0.24 (환원불가)
신뢰: conf = 1−H_norm, D(x) 분위수
결론: 성공확률 X → 패턴 유사도 점수 ✓

이 프로젝트에서 사용한 모든 수학 도구의 집약. 문제 정의부터 한계 증명까지 하나의 수식 체계로 연결된다.

예상 질문과 답변

질문을 받으면 성능 수치보다 검증 구조와 해석 범위로 답한다

Q. RMSE가 낮으면 무조건 좋은가?
A. 낮을수록 좋지만 baseline 대비 개선폭, fold 안정성, 잔차 구조를 함께 봐야 한다.
Q. 이 점수는 실제 성공확률인가?
A. 아니다. 학습 데이터에서 관찰된 성장기업 패턴과의 유사도 점수로 해석한다.
Q. 왜 Expected Value 모델인가?
A. target이 8개 이산값이므로 class 확률의 기대값을 계산하는 방식이 구조적으로 적합했다.
Q. R²가 낮으면 실패인가?
A. 강한 설명모델은 아니지만, baseline 대비 개선과 해석 범위 정의가 핵심 성과다.
Q. 데이터 양이 부족한 것 아닌가?
A. Learning Curve에서 75%→100% 개선폭이 작아 데이터 양 부족을 주원인으로 보지 않았다.
Q. train/test 분포가 달라서 그런가?
A. 엄격한 Adversarial AUC가 0.5298로 0.5에 가까워 분포 차이는 작다고 판단했다.
Q. 디스플레이 외 산업도 가능한가?
A. 가능하지만 산업군별 RMSE와 외삽 위험을 함께 봐야 한다. 모든 산업에 동일 신뢰도로 적용하지 않는다.
Q. 수학과 캡스톤에서의 수학적 기여는?
A. 오차함수, 교차검증, 잔차, 기대값 모델, OOD 거리로 예측값의 신뢰 범위를 수학적으로 검증했다.

슬라이드 목차

용어 사전

Baseline

모델이 최소한 넘어야 하는 기준선. 이 프로젝트에서는 전체 평균 예측 RMSE 0.2417이 핵심 기준선이다.

MAE

예측값과 실제값 차이의 절댓값 평균. 평균적으로 얼마나 틀렸는지 직관적으로 보여준다.

RMSE

오차 제곱 평균의 제곱근. 큰 오차에 더 민감하므로 극단값 예측 실패를 잘 드러낸다.

OOF

Out-of-Fold 예측. 교차검증에서 각 validation fold에 대해 얻은 예측값을 모은 것이다.

Expected Value

각 class의 확률과 class 값을 곱해 더한 기대값. 성공확률이 이산형일 때 유용하다.

Residual

잔차 eᵢ = yᵢ − ŷᵢ. 모델이 어디서 과대예측 또는 과소예측하는지 분석한다.

Adversarial Validation

train과 test를 구분하는 별도 모델을 만들어 분포 차이를 진단하는 방법이다.

OOD distance

새 데이터가 학습 데이터 분포에서 얼마나 떨어져 있는지 보는 표준화 거리다.
